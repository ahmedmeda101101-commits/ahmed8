# نظام ماكينة التطريز — النسخة المطورة

## ما تم تطويره في هذه النسخة

### التشغيل والحركة
- فواتير المبيعات والمشتريات أصبحت متعددة البنود داخل الفاتورة.
- اختيار العميل/المورد والصنف من قوائم من قاعدة التعريفات.
- السعر يملأ تلقائيًا ويمكن تعديله.
- الدفع النقدي يضيف حركة خزينة مرتبطة بالفاتورة والطرف تلقائيًا.
- حركة الخزينة أصبحت أقرب لهيكل شيت الخزنة: نوع الحركة، الطرف، التحميل/التصنيف، التحليل، البيان، المبلغ، الملاحظات.
- حفظ محلي للحالة عند عدم وجود DATABASE_URL حتى لا تضيع البيانات عند إعادة تشغيل السيرفر.

### العملاء والموردون
- شاشة أرصدة مستقلة للعملاء والموردين.
- زر "كشف حساب" لكل عميل أو مورد.
- كشف الحساب يعرض المدين والدائن والرصيد التراكمي.
- التحصيل/السداد المرتبط بالطرف يدخل في الكشف.

### Dashboard
- مؤشرات المبيعات والمشتريات والخزينة والمخزون وصافي النشاط.
- رسم المبيعات والمشتريات شهريًا.
- تنبيهات المخزون المنخفض.
- مؤشرات الذمم المدينة والدائنة.
- مركز مطابقة Excel.

### التقارير
- تقارير المبيعات والمشتريات والخزينة والمخزون والشركاء والأصول والإهلاك.
- قائمة الدخل والتدفقات النقدية وميزان المراجعة والمركز المالي.
- تصدير Excel وطباعة/PDF مع معاينة كاملة للتقرير قبل الطباعة.
- تقرير الخزينة يحتفظ بكل أعمدة شيت "حركة الخزينة" المهمة، بما فيها كود الحساب (G) وكود تحليل البند (K) ورقم السند والمستفيد والبيان والملاحظات.
- أي حركة خزينة يدوية أو ناتجة عن فاتورة/مسير تُنشئ قيدًا محاسبيًا مقابلًا، مع ترحيل التفاصيل نفسها للقيد.
- كشوف أرصدة الأطراف وكشف الحساب التفصيلي.

## التشغيل على Windows
إذا منع PowerShell تشغيل npm.ps1 استخدم:

```powershell
npm.cmd install --legacy-peer-deps
npm.cmd run dev
```

ثم افتح:

`http://localhost:3000`

> لا تستخدم `npm audit fix --force` أثناء الاختبار الأول حتى لا تتغير إصدارات الحزم.
